# FreelanceOS

Enterprise Product & System Design implementation.

## Project Structure
- `apps/web`: Next.js web application
- `services/api`: Cloud Run API
- `services/ai-orchestrator`: AI orchestration pipeline
- `functions/`: Firebase Functions
- `packages/`: Shared domain logic, contracts, and configurations
- `docs/`: Architecture and runbooks
- `firebase/`: Firebase rules and emulator configs
